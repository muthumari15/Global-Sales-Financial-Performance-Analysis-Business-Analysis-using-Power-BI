**Global Sales & Financial Performance Analysis – Business Analysis using Power BI**

This project focuses on analyzing a Global Sales & Financial Performance dataset using Microsoft Power BI. It includes data loading, data cleaning in Power Query, data modeling (star schema), DAX measures, and interactive dashboard development.The dashboard provides insights into sales performance, profit, product categories, regions, monthly sales trends, order counts, and employee performance.

**Key Features:**

* Data Loading and Cleaning (Power Query)
* Data Modeling with Relationships (DimCustomer, DimDate, DimEmployee, DimGeography, DimProduct, FactSales)
* DAX Measures (Total Sales, Total Profit, Total Quantity, Order Count, Average Sales)
* KPI Indicators Page
* Sales Overview Analysis (Column, Bar, Line and Donut Charts)
* Interactive Dashboard with Slicers
* Business Insights and Recommendations

**Key Insights:**

* Total sales are 70.64M with a profit of 25.12M
* About 300K units were sold across about 100K orders
* Average sales per order are 706.36
* Some products and categories perform much better than others

**Tools Used:** Microsoft Power BI, Power Query, DAX

**Objective:** To transform raw sales data into meaningful insights and provide data-driven recommendations, such as promoting low-performing products, offering discounts in low-sales periods and using product bundles to increase order value.
